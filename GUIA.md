# Guía de uso — Editor Parallax

> Esta guía es para Daniela. Instrucciones paso a paso para las tareas más comunes.

---

## Requisitos

- Tener Node 20+ instalado
- Tener Yarn instalado
- Los 4 repos clonados y con dependencias instaladas (correr `./bootstrap.sh` si es máquina nueva)

---

## Arrancar el editor

```
yarn editor
```

Se abre automáticamente en el navegador en `http://localhost:3000`.
