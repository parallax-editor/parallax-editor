# parallax-editor

Editor local tipo Illustrator para crear y editar sitios parallax. Solo corre en la máquina de Daniela, nunca se expone a internet.

## Setup

```bash
yarn install    # crea symlink a parallax-engine automáticamente
```

## Uso

```bash
yarn editor     # arranca el editor en http://localhost:3000
```

## Bootstrap (máquina nueva)

```bash
./bootstrap.sh  # clona repos, instala deps, configura links
```
