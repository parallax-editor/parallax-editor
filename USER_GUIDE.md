# User guide — Parallax Editor

> Step-by-step instructions for the most common tasks in the editor.

---

## Requirements

- Node 20+ installed
- Yarn installed
- `parallax-engine` installed (pulled in automatically by `yarn install`; run `./bootstrap.sh` on a fresh machine)

---

## Start the editor

```
yarn editor
```

It opens automatically in the browser at `http://localhost:3000`.

---

## Configure workspaces

The editor starts with no workspaces. Add your own from the UI: each workspace
points at any folder on disk that follows the flat
`<workspace>/content/<slug>/site.json` layout.
